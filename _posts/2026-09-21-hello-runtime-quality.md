公众号适合传播，但文章真正长期可控的载体，应该掌握在自己手里。

这个站会主要记录我在 AI Testing、Harness 和 Agent Reliability 方向的工程实践：遇到了什么真实问题，怎么验证，哪些方案失败了，以及最后沉淀出了什么可以复用的能力。

我希望逐步把这些内容串成一条完整链路：

**Change → Agent → Harness → Trace → Verification → Failure / Root Cause → Regression → Quality Gate**

这里不会追求高频更新，重点是让每篇文章最终都能成为可检索、可引用、可持续迭代的技术资产。
