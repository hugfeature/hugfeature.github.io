已经遇到执行问题，可以从下面选读；第一次接触 Harness，建议先看按顺序编排的系统教程。

按当前问题选读

  • 任务停住，需要无人值守继续：有界自主运行，检查进展、停止原因和恢复条件。
  • 工具失败，重试可能重复产生副作用：超时、重试、预算与副作用。
  • Agent 说完成了，却没有可靠证据：设计结果证据契约，明确什么能证明完成。
  • 不断验证，预算用完仍未交付：重复验证与预算耗尽，区分新增证据与重复工作。
  • 流程被跳过，结果却显示通过：执行契约与流程偏移。
