按当前问题选读

  • 显示通过，过程却不可靠：Agent 最危险的不是失败，而是“最终通过，但过程已经失控”。先区分最终结果与执行过程。
  • Agent 跳过了必要步骤：Agent 会跳步骤：从测试用例生成失败到 Execution Contract Drift。定位执行契约与阶段证据。
  • 完成了，却拿不出证据：结果正确就够了吗？给 Agent 设计 Evidence Contract。定义可核对的完成条件。
  • 同类故障反复出现：一次 Agent 失败，怎么变成一条 Regression Case？。把一次失败转成可复现回归。
